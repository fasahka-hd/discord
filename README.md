# Discord Clone 🎧

Полнофункциональная копия Discord: веб-приложение с голосовыми каналами (WebRTC), чатами в реальном времени, друзьями, личными сообщениями и серверами. Тёмная тема в стиле Discord (+ светлая).

## Запуск

```bash
npm install

# продакшн-режим (сборка + сервер на :3001)
npm run serve

# либо режим разработки (горячая перезагрузка, :5173)
npm run dev
```

Откройте **http://localhost:3001** (или :5173 в dev-режиме).

Демо-аккаунт: `admin` / `admin123` (создаётся автоматически, с сервером «Demo Server»). Это аккаунт **администратора платформы** — у него в настройках есть вкладка «Выдача бейджей».
Чтобы проверить войс и чат между пользователями — зарегистрируйте второй аккаунт в другом браузере/инкогнито.

## Возможности

| Раздел | Что есть |
|---|---|
| 🔐 Аккаунты | регистрация, вход, смена пароля, аватар (с авто-ресайзом), bio, статусы (онлайн / не активен / DND / невидимка) |
| 🏅 Бейджи профиля | 90+ настоящих иконок Discord (модераторы, охотники за багами, HypeSquad, Nitro, бусты, возраст аккаунта и т.д.); администратор платформы выдаёт их из настроек или прямо из карточки профиля — бейджи сразу появляются у всех в профиле и списках. В чатах видны только служебные значки (Сотрудник, боты, «Я здесь новый») |
| 🛡️ Права от значков | Бейдж «Сотрудник» даёт право приостанавливать и блокировать аккаунты и удалять любые сообщения; «Сертифицированный модератор» — приостановку; «Alumni модераторов» — удаление сообщений. Ограниченный аккаунт ловит экран блокировки при входе и в рантайме |
| 📞 Звонки в ЛС | Как в Discord: плашка звонка с аватарами, таймером и круглыми кнопками (микрофон/звук/экран/завершить), «Звоним…» до ответа собеседника и модалка входящего звонка с пульсирующим аватаром и кнопками Принять/Отклонить |
| 👤 Карточка профиля | Компактный поаут как в Discord: баннер, аватар, имя + бейджи (перенос по строкам), статус, действия, «Обо мне», общие серверы/друзья, заметка и меню модерации для сотрудников |
| 👥 Друзья | заявки по имени, принятие/отклонение/отмена, удаление, списки «Онлайн / Все / В ожидании» |
| 💬 Личные сообщения | создание бесед, закрытие бесед, непрочитанные, звонки 1-на-1 |
| 🖥 Серверы | создание, вход по коду-инвайту, роли (владелец/админ/участник), кик, выдача админки, настройки (название, цвет иконки), удаление |
| 📺 Каналы | текстовые и голосовые, создание/переименование/удаление, тема канала, категории |
| ✍️ Чат | realtime через WebSocket, редактирование, удаление, ответы (reply), реакции, упоминания @user с автодополнением и подсветкой, markdown (**жирный**, *курсив*, `код`, ```блоки```, ~~зачёркнутый~~, ссылки), вложения (картинки + файлы), пагинация истории, разделители дат, индикатор «печатает…», поиск по сообщениям и людям |
| 🔊 Войс | WebRTC mesh (STUN), подключение/выход, mute/deafen, список участников в канале, подсветка говорящих (голосовой анализатор), таймер соединения |
| ⚙️ Настройки | профиль, безопасность, «Голос и видео» (выбор микрофона + метр уровня), внешний вид (тёмная/светлая тема, размер шрифта) |
| 🎨 UI | контекст-меню, тултипы, модалки, бейджи непрочитанных, эмодзи-пикер, лайтбокс для картинок |

## Архитектура

```
server/          Node.js + Express + ws + better-sqlite3 (Node ≥ 18, prebuilt-бинарники)
  index.js       — bootstrap, статика dist/
  api.js         — REST API
  ws.js          — realtime-хаб (чат, presence, typing, voice signaling)
  db.js          — схема SQLite (data/discord.db)
  auth.js        — JWT в httpOnly cookie + bcrypt
  state.js       — presence и voice-комнаты в памяти
src/             React 18 + Vite
  lib/store.js   — минимальный стор на useSyncExternalStore
  lib/ws.js      — WS-клиент → диспетчер событий в стор
  lib/voice.js   — WebRTC-менеджер (mesh, mute, speaking-детект)
  components/    — Layout, Chat, Friends, Settings, Modals, Badges, …
shared/
  badges.js      — каталог бейджей (единый источник для сервера и клиента)
public/badges/   — настоящие SVG/PNG-иконки Discord (mezotv/discord-badges, MIT)
```
